## Beta 2 for v1.0.0

This is a beta: Things will change and worlds might break between versions. Please make frequent backups of your world.
If you have any feedback, suggestions or problems, please let me know!

### Additions
- Create: Numismatics Compatibility. When Create: Numismatics is installed, spurs can be exchanged to dollars using a Finances Manager. The exchange rate is configurable.
- Villagers now follow company members holding emeralds (similar to sheep following players holding wheat)

### Removals
- Removed unused `freeStorage` field from Legal Form Definitions

### Changes
- Upgrade Requirements for Partnership: Minimum Fulfilled Orders 1 >>> 10
- Minimum Neoforge Version: 21.1.250 >>> 21.1.219

### Fixes
- Fixed an overflow issue with the header of the Property Manager UI
- Fixed a grammatical mistake in the Kontor Desk Bankruptcy tab
- Fixed a long overflow with large revenues in the Finances Manager UI
